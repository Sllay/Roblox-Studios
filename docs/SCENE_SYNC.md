# Scene Sync — P3

Run the dedicated Scene Sync workflow before planning and after every remote write. Select game, place and environment; record=true persists an observed baseline in Git under games/maps/<game>/docs/sync/<place>/<environment>.json. The workflow uses the same concurrency group as the corresponding staging writers and never calls SavePlaceAsync. It pushes without force: a concurrent Git change fails rather than overwrites. Artifacts include inventory.json and changes.json. Pull main after success.

Coverage: Workspace, ReplicatedStorage, ServerScriptService, ServerStorage, StarterPlayer, StarterGui, StarterPack, Lighting, SoundService, Teams and ReplicatedFirst. Includes hierarchy and class, stable managed IDs when present, explicit name/class/ordinal paths, ambiguity flags, selected part/model/material properties, script source hashes (not source), hashed attributes/tags, SurfaceAppearance authoring maps, Lighting settings and native voxel digests for explicitly registered bounded regions. Unknown objects are discovered, not executed or deleted. Unmanaged rename/reparent can appear as removal/addition; ambiguous paths cannot be edited without explicit adoption. Engine-provided defaults can be included. This is not a full serialization or full-world terrain scan; arbitrary class properties, asset binary content, unsaved Studio changes and runtime-only objects are outside this contract. No secrets or script body exported.

Three-way reconciliation: base = last observed state, remote = current published state, desired = explicit keyed record intents (optional --desired JSON map). Remote-only changes are reported, local-only intents preserved, divergent edits conflict, equal changes converge. No absence-as-deletion. Do not advance a baseline while explicit local/conflicting intents remain. A sync is observation, not automatic adoption of source code. Git history tracks observations; rollback requires operation-specific inverse or Roblox version recovery, not just a hash.

Writers call require_current(target,key,expectedVersion) before saving; it independently re-reads the inventory and refuses if observed version or digest differs. Existing version and source/terrain checks remain. Full-place upload still blocked unless declared authoritative. No automatic promotion. Use the workflow then git pull before editing. After a write, run Scene Sync again before another write. Cloud requests can be rate-limited; never retry an uncertain save.
