# ADR 0003 — C1 stage-local cache and explicit evidence contracts
Status: implementation, subject to C1 CI.
Reuse C0 atomic writes, hash verification, pinned Blender preflight and BVH geometry buffers. Adopt a versioned JSON/dataclass contract, local job directories with flock, immutable per-attempt outputs and stage-specific dependency keys. UV and rig are sibling branches after optimization so a paint change cannot invalidate geometry or rig. Use C0 render worker functions on exact synthetic meshes; no learned depth is claimed. CPU baseline mandatory; optional GPU/learned candidates unavailable until validated. C1 implements intake and reference crops only; C2-C6 stages blocked. Future production backends must provide versioned stage adapters and input/output contracts. See docs/benchmarks/creature-factory-next/C1.md.
