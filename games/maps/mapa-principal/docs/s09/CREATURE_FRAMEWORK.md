# S09.5 Creature Framework / Book — foundation
User requirements 2026-11-14. V25 unchanged. This is source-only core, no live spawning, UI, datastore, combat or navigation adapter yet.
## Identity and data
Permanent random six-digit string species IDs (100000..999999), collision checked on registration, never recycled. First species Galinha 210080. Per-instance runtime ID separate (server GUID). Future items reserve four digits (1000..9999) in separate namespace; no Item Registry until item design. Server catalog owns name, description, category, disposition, preview PNG asset reference, biome tags, asset references, base stats, growth, profile. Book reads registry projection, never hand-authored duplicate. Preview image asset upload pending. Client sees only public metadata and opaque UI selection handles; developer ID visibility is server-authorized. Technical IDs are not secrets or authorization credentials.
## Book and progress
Book categories mobs/items/missions, passives/neutral/aggressive and taxonomy filters. Only mobs now; future categories register providers. Discovery by server-validated kill, interaction, or meaningful observation (threshold not approved yet), idempotent per species; dev summons excluded by default. Ledger first timestamp, reason, merge takes earliest, ties deterministic. Completion discovered/eligible entries; adding new entries can lower percentage, show counts and category/version. Hidden/retired content policy to be reviewed. Runtime persistence planned DataStore UpdateAsync with monotonic merge, load failure safe, dirty queue, budget and retry; no live DataStore yet. Alphabetical and discovery order. Ordinary player does not receive technical ID in projected rows. Book UI planned static 2D image, no 3D viewport.
## Levels
Feature off for runtime by default. Shared stats evaluator used by gameplay and Book level 1/10 preview; provisional linear growth per level: HP/damage +8% of base, walk/run +1%, cap 10. Chicken HP 20, damage 0, reference gait speeds .397/.736 studs/s at native scale, level 10 HP 34; balance not approved. Zero base damage remains zero. Do not imply nonlinear curves or final balancing. Future level selection in spawn config; never duplicate scaling in UI.
## AI
Inspired by LimboAI (https://limboai.readthedocs.io/en/stable/): HSM for lifecycle/survival/routine/combat, behavior trees for reusable actions/conditions with SUCCESS/RUNNING/FAILURE, typed blackboard, event interruption and action cancellation, cooldowns, hysteresis. Current MobBrain is a pure passive-prey decision policy with shared state/intent, not yet full generic HSM/BT executor. Next: reusable executor, perception spatial queries/LOS/noise, path planning, steering, dynamic threat memory, blocked path escape scoring, predator/prey/food, attack windup/recovery and ranged LOS/cover. Server authoritative; clients render/interpolate. Flee on hit/fast approach/predator, slow approach tolerated outside personal space; calm hysteresis, blocked escape recovery. Actual sight, movement and terrain not yet integrated. Passive never attacks. NPC melee/ranged and predator use shared capabilities, not copy-paste brains.
## Simulation and spawn
Vale Esmeralda (emerald_valley), existing nine chunks; no other biomes invented. Spawn profiles separate from registry, use verified terrain/ground, reject water/steep slopes, collision clearance, safe distances, retry other valid cells with bounded attempts. Population caps global/per biome/chunk/species, spatial index, despawn hysteresis, leases, per-player relevance, no unlimited spawning. Current scheduler bounded round-robin with tier hysteresis and 10k logical-slot test; no claim of 10k physical mobs. Proposed near/mid/far/abstract decision intervals .1/.5/2/10s and 50/120/250 studs thresholds provisional; real measurements required. Later spatial grid and due queues, shared path request budget, independent motion/animation LOD, client streaming, profiling. Abstract records no rig/physics, maintain bounded ecological state; no gameplay-critical loss of identity. Avoid all-pairs or one Heartbeat per entity.
## Developer command contract
/summon mob 210080 3 here true or /summon mob 210080 3 10 5 -20 false. Server role check (allowlist/group rank server configuration), validate species/quantity/finite positions/ground/caps, audit actor/time/result. true enables AI, false static (no AI locomotion; no discovery credit by default). Current parser returns plan only; no remote/console or spawning; authorization arg must be supplied by trusted server wrapper. Default max 20 per command provisional. Future optional level with feature flag.
