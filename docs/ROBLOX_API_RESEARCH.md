## Official API opportunities
- [Luau Execution](https://create.roblox.com/docs/cloud/reference/features/luau-execution): version-specific tasks, binary inputs, task logs, up to 5 min and 10 concurrent per place in current docs. Use pinned historical reads for A/B; retain single writer and no blind write retry. Existing 90s budget remains. Binary transport for compact RBXM/voxel payloads is planned, not implemented. Task logs can support bounded debugging, not unfiltered secrets or full script export.
- [Studio MCP](https://create.roblox.com/docs/studio/mcp): screen_capture, start_stop_play, character_navigation, console, edit/client/server Luau, search_game_tree, inspect_instance, generation of mesh/material/animation and asset search. Optional Studio backend only. [Open Cloud via MCP](https://create.roblox.com/docs/studio/mcp-open-cloud) uses user-granted per-game scopes; no exposed token. Do not grant production or monetization scopes. [Studio setup](https://create.roblox.com/docs/studio/setup) Windows/macOS, not native Android/iOS. Investigate authorized host rather than promise unavailable cloud Studio.
- [Terrain](https://create.roblox.com/docs/reference/engine/classes/Terrain): 4-stud SolidMaterial/SolidOccupancy/LiquidOccupancy; deterministic read/paint/sculpt, exact hash and per-region field cache. Surface Fields already implemented. Heightfield is single top surface estimate, not caves/overhangs or physical ray hit. Add 3D connectivity, watershed/flow paths, coast and water clearance, normals and spatial queries.
- [WorldRoot](https://create.roblox.com/docs/reference/engine/classes/WorldRoot): Raycast, Spherecast, Blockcast, GetPartBoundsInBox broad phase, GetPartsInPart precise overlap. Existing headless terrain ray returned unsupported/no hit; probe actual context before relying. Real server/client tests remain necessary.
- [EditableMesh](https://create.roblox.com/docs/reference/engine/classes/EditableMesh), [AssetService](https://create.roblox.com/docs/reference/engine/classes/AssetService): vertex/face geometry and local raycast, mesh construction, content/permissions and memory budgets. Use approved existing mesh read to assess trunk cross-sections and topology, not mesh bounding box alone. Published experience APIs require eligibility/settings; do not enable automatically. Offline mesh extraction where authorized, manual calibration fallback.
- [Assets](https://create.roblox.com/docs/cloud/reference/features/assets): metadata, versions, quotas, asset permissions and 3D thumbnails; many endpoints beta. Check dependencies and ownership/access; permission is not license. No asset reupload without review. [SerializationService](https://create.roblox.com/docs/reference/engine/classes/SerializationService): existing RBXM PBR checks; extend scoped preimage backup and roundtrip, not claim full Place backup.
- [Place publishing](https://create.roblox.com/docs/cloud/guides/usage-place-publishing): documented limitations for SurfaceAppearance, EditableMesh/Image, PartOperation, BaseWrap. Preserve incremental SavePlaceAsync flow; no full Rojo upload of existing map. [Places](https://create.roblox.com/docs/cloud/reference/features/places): version history experimental and instance APIs beta/collaborative, do not replace proven sync or assume rollback.
- [Studio testing](https://create.roblox.com/docs/studio/testing-modes): StudioTestService, VirtualInput, device/network simulation. Useful for reproducible client/server scenarios, but Studio only and device emulator is not physical mobile benchmark.
- [Stats](https://create.roblox.com/docs/reference/engine/classes/Stats), [MicroProfiler](https://create.roblox.com/docs/performance-optimization/microprofiler): frame time, memory, physics and render budgets; property availability varies by context. Add runtime opt-in diagnostics with p50/p95, no raw player data.
- [PathfindingService](https://create.roblox.com/docs/reference/engine/classes/PathfindingService): walkable spawn-to-landmark route checks, agent size and cost. No path in headless is not proof of broken live navigation.
- [CollectionService](https://create.roblox.com/docs/reference/engine/classes/CollectionService): server-owned component tags and streaming lifecycle, replace periodic full tree scans with maintained registry where practical.
- [Analytics](https://create.roblox.com/docs/cloud/guides/analytics): aggregate experience metrics, platform breakdown where supported, later playtest/live insights; not substitute for frame captures or individual runtime measurements.

## Quality architecture
1. World model: surface fields + spatial index + semantic catalog + unit-aware placement rules; output map overlays and quantitative budgets.
2. Asset lab: inspect geometry, scale, pivot, material, dependency, rights; exact per-species trunk profile and foliage anchors; render with Studio if connected.
3. Test runner: scenario manifest (version, camera, inputs, expected constraints, budget), replay and evidence; no guessed mobile approval.
4. Transaction: single-writer, scoped snapshot/receipt, independent read and recovery; default module duplicate accumulation still open. Distinguish archive rollback from proven restore.
5. Agent policy: discover documented APIs and actual probe status, use typed plans, explicit staging authorization, evidence of expected outcome, no production or arbitrary external scripts.

First priorities: geometry/physics probe and terrain spatial cache -> placement/collider rules -> runtime test harness -> Studio backend when available. Research does not claim all these APIs are enabled in our current environment.
