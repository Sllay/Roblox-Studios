# GDD — Sandbox Demo

## Objetivo
Cenário de teste mínimo para verificar scripts, instâncias declarativas e múltiplos Places compilados separadamente.

## Loop
O usuário entra no Place, encontra uma plataforma e SpawnLocation, e os scripts de inicialização são executados.

## Não objetivos
Nenhuma economia, loja, inventário, persistência ou publicação automática. É um exemplo técnico, não um jogo completo.
