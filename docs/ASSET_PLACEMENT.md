# Placement profiles — P1.1

A bounding box is geometry, not the intended ground contact. Every new pack import requires a reviewed profile tied to the selected model. Supported mounts: sit_on_ground and bury_in_ground, upright only. Wall/ceiling/tilt/custom anchors require future explicit policies; unknown profiles fail closed. Ground is an explicit allowlist of anchored collidable Workspace children (Terrain may be included only after validation). Five rays sample center and support footprint, reject water, missing ground, slope and height variance. The placement probe returns pivot Y = groundY - bottomOffset - burialDepth; apply recomputes and rejects a changed reviewed position. No blanket sinking or random offset. Ground allowlist is scene-specific and must be reviewed for another scene. Tree_01 initial burial 6 studs, provisional pending mobile check. Historical P1 v2 plan remains evidence, cannot be reapplied under new policy.

Use pack_import.py placement-probe --asset-id ... --selector ... --position X 0 Z, then use the returned pivot in prepare. Profile and ground sample evidence are persisted with managed objects. Geometry and PBR unchanged. The first calibration is an estimate from the user's mobile screenshots, not mesh-level automatic contact detection.
