# Assets — Between Kingdoms

Reaproveitar os assets próprios/aprovados de Black Island via `asset-library/` e o catálogo global, sem copiar conteúdos sem licença nem alterar o jogo de origem.

Visual: stylized cartoon 3D; personagens R6 com roupas medievais. Descoberta de catálogo por APIs Roblox apenas com filtros, cache e revisão prévia; roupas externas aleatórias não são automaticamente compatíveis, seguras ou autorizadas. Terrain nativo gerado com a ferramenta existente após verificar contratos e testes.
