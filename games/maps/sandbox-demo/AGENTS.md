# Agentes — sandbox-demo

Este jogo serve exclusivamente para validar a infraestrutura do monorepositório, do Rojo e do pipeline GitHub Actions. Não o transformar em projeto de produção sem atualizar o GDD, IDs e critérios de qualidade.

Leia `GDD.md`, `ARCHITECTURE.md` e `game.manifest.json`. Alterações devem preservar compilação independente de `lobby` e `arena`.
