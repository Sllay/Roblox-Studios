# Native Terrain Builder — P2.1

Agents must use the declarative plan and native Terrain channels, not independent Parts, Air excavation for paint, or floating water. Roblox grid resolution is 4 studs. https://create.roblox.com/docs/reference/engine/classes/Terrain

Plan: bounded 3D grid, seed, base height, edge blend, multi-layer fractal noise (wavelength, amplitude, octaves, lacunarity, persistence, seed offset), optional domain warp, surface/soil depth, lake center/radius/depth/level/bank rise/bank width/shore irregularity/sand width, path polyline/width/material. All geometry derives from one continuous height field. Native solid occupancy filled bottom-up. Water uses LiquidOccupancy, bounded by solid occupancy and a constant lake plane; dry neighboring columns must contain water. Solid floor must exist under every column. Paint changes only SolidMaterial; path and shore never alter occupancy. Readback asserts exact occupancy and water invariance through painting. Separate material layers Grass, Ground, Rock, Sand. Existing Terrain or intersecting Parts cause refusal; no Terrain:Clear. This first scope is new bounded regions, not editing arbitrary existing caves or hydrodynamics.

Workflow Native Terrain Builder (staging): preview generates a height/material map without writes. Apply requires expected Place version and explicit confirmation, performs preflight, writes native channels, verifies readback, saves, independently verifies SHA-256 of voxel data and checks Workspace object diff. Only staging. Current pilot 256x256 studs to east of spawn; original Baseplate and Tree_01 remain. The lower base is supported by Baseplate, lake has solid floor. Lab cleanup is restricted to owner-marked P1 test instances. Preview is schematic, not client screenshot. Need actual mobile validation of seams, shore, swimming and performance. No terrain outside region is modified. Terrain content is not covered by normal Workspace snapshot; dedicated voxel hash is authoritative for this region. Terrain has 4-stud resolution, no promise of sub-voxel material boundaries.

Usage: python tools/terrain_builder.py preview --plan games/maps/mapa-principal/game/terrain/pilot-valley.json. Apply only after preview review; --expected-version 3 --confirm-staging. Verify with --digest from save.json, never retry a save blindly. Future: editing existing terrain with baseline digest, region paint brushes, spline/rivers, caves with 3D density, mesh-safe placement and terrain region catalogs.

For placement, the shared solver accepts explicitly allowed native Terrain and uses water-aware rays: a Water hit is rejected instead of silently planting on the lake bed. The first preview (43138809195) generated 4,096 columns, 219 wet columns, 198 path columns, 404 sand columns, 21,297 occupied solid voxels and 334 water voxels. Outer lake blend is smooth toward the surrounding noise field. No remote save in preview. The pilot is bounded and does not replace Baseplate or the original Tree_01.

## Paint existing terrain

`tools/terrain_paint.py preview --plan games/maps/mapa-principal/game/terrain/paint-example.json` reads native voxels and returns the versioned baseline, geometry digest, exact intended material digest and changed count. Masks: path polyline, circle, ring, rectangle. Filter source materials, choose depth in surface cells, skip underwater columns unless explicitly allowed. Apply accepts the exact reviewed baseline and plan, checks current Place version/digest, writes only SolidMaterial and checks exact solid/liquid equality. Independent verification confirms material and geometry digests. Use the manual Native Terrain Paint workflow; pass the preview run ID for apply. No sculpting or water operations in this tool. P2 test adds a connected short branch to the existing dirt trail, not a separate terrain volume.

Limitations: heightfield pilot supports one lake and one base path per creation plan, plus independent masks for later painting. It is not a general 3D cave/overhang editor or arbitrary terrain sculpt editor; existing regions are protected from overwrite. No water-flow simulation; Roblox native static terrain water. Terrain generation and painting validated structurally, mobile swimming, shoreline appearance, edge transition and FPS pending.
