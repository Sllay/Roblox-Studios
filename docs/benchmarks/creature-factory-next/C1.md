# C1 — Foundation contracts and persistent DAG
Implementation checkpoint on feat/creature-factory-next, PR #9. C0 remains the measured baseline.
## CLI
Run from repo root. The host needs Python 3.11+, Pillow for intake and NumPy for fixture evidence. Blender 4.3.2 official bundle is SHA-256 pinned in CI; embedded NumPy is probed before rendering.
```sh
python -m tools.creature_factory.next preflight --out dist/c1-preflight --profile thin_surface --blender /path/to/blender
python -m tools.creature_factory.next fixtures --out dist/c1-fixtures --blender /path/to/blender --resolution 128
python -m tools.creature_factory.next build --manifest dist/c1-fixtures/wavy/manifest.json --out dist/c1-job
python -m tools.creature_factory.next inspect --job dist/c1-job
python -m tools.creature_factory.next validate --job dist/c1-job
python -m tools.creature_factory.next resume --job dist/c1-job
python -m tools.creature_factory.next legacy-rabbit --source asset-library/references/rabbit-v1
python -m unittest tests.test_creature_next_c1 -v
```
Legacy command emits JSON; save alongside the originals in a separate staging directory with copies of the original PNGs, not into the immutable asset-library. Historical crops derive from PANELS in rabbit_organic_reference.py. Camera calibration is unknown and top/bottom absent.
## Data contract
contracts.py contains version 1 dataclasses. AssetManifest uses seven source-relative crops of one PNG with SHA256, explicit camera status, units/axes/scale, optional rig, parts, landmarks, protected areas and material/identity metadata. Legacy allows multiple sources and missing views. Known and estimated camera matrices are checked for rigid right-handed transforms. C1 checks structural consistency, alpha threshold/margins and file integrity; anatomical consistency is C2. EvidenceBundle uses camera-forward float32 depth, world XYZ unit normals, bool mask and zero background, pixel-center top-left origin. GeometryArtifact binds counts, units and hash. StageResult and JobManifest retain state, config, dependency keys, attempts, outputs and metrics. ExportTarget separates platform limits from master.
## DAG and caching
intake -> reference_ready -> evidence_ready -> master_ready -> quality_checked -> optimized. From optimized, UV -> materials and rig are separate branches; packaging joins them. review_ready follows packaging. Only intake/reference extraction are production runners in C1. All later stages report blocked; optional rig skipped. Injected test runners exercise the full graph solely for cache tests, not as production assets.
A stage key binds its configuration, version, backend, dependency keys/attempt IDs, and root source hash. Production runner implementation fingerprints are included. Each attempt has a unique directory; output hashes verified on resume. On corruption or input/config change, affected stages and descendants rerun; other branches remain cached. State writes atomically using C0 writer; Linux flock releases on process death; partial attempts preserved. Retrying transient errors is bounded; deterministic failure not retried. Source mutation during a stage rejects the attempt. Paths confined to job root/source directory. No publishing.
## Fixture definitions
Flat and wavy: same 3x2 XY footprint, thickness .08 along Z; wave amplitude .22, wavelength 1.5, cosine envelope. Convex and concave: same rectangle and rim, center +/-.35, thickness .55. Asymmetric: deliberately different extensions. Articulation: separate body/limb gap .15, joint metadata and thin strand width .08. Technical solids, not artistic animals. All seven views share known orthographic scale 4.4 and camera distance 8; Blender C0 BVH raycasts produce mask/depth/geometric normals; Cycles CPU produces rendered PNGs. GLB, blend, manifest, evidence, geometry parameters and review sheet saved per run. Fixture gate verifies same top masks, depth difference and normal difference.
