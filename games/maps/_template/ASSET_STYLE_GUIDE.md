# Guia de estilo e seleção de assets

- **Direção artística:** pendente de definição do jogo.
- **Biomas e ambientes:** somente os biomas estabelecidos no GDD.
- **Qualidade visual:** escolher modelos coerentes entre si; não selecionar somente pelo nome.
- **Critérios técnicos:** orçamento de Parts/MeshParts, colisões, texturas, distância de renderização e desempenho mobile devem ser medidos.
- **Direitos e segurança:** nenhum modelo importado sem autorização, inspeção de scripts e verificação de permissões/licenças.

O workflow Asset Discovery cria candidaturas **não aprovadas** em artifacts do GitHub Actions. A aprovação exige revisão visual e de segurança. A busca não altera Places.
